# 中文企业名称

依据：网上公开的中文企业名称匹配经验（jieba 分词去冗余词；全称结构化为 RXIO；按规则猜简称；最短编辑距离 + 分部加权 8:1:1），结合英文流程的经验。代码在 `scripts/name_std_zh.py`，已用常见名称测试（见文末），尚未在完整任务中检验——第一次用于真实数据时，先抽 100 个名称人工看拆分结果，再补词库。

## 1. 名称结构

工商登记名称一般是 **行政区划 R + 字号 X + 行业/经营特点 I + 组织形式 O**：

| 全称 | R | X | I | O |
|---|---|---|---|---|
| 深圳市万网博通科技有限公司 | 深圳市 | 万网博通 | 科技 | 有限公司 |
| 广东省深圳市腾讯计算机系统有限公司 | 广东省深圳市 | 腾讯 | 计算机系统 | 有限公司 |
| 阿里巴巴（中国）网络技术有限公司 | （中国）| 阿里巴巴 | 网络技术 | 有限公司 |
| 中国工商银行股份有限公司北京分行 | 中国 | 工商 | 银行 | 股份有限公司；分支：北京分行 |

**字号 X 是辨识部分**，相当于英文流程的"核心名称"；地区和行业相当于"泛用词"。

## 2. 标准化（`parse`）

1. 规范化：全角转半角（NFKC）、去空格和标点、统一括号、字母大写。繁体转简体需要 opencc（遇到港台数据时安装）。
2. 括号内容单独取出：地区（上海、中国）并入 R；"集团""控股"等视为组织形式；其他作为别名。
3. 分支机构（分公司、分行、支行、办事处、营业部…）单独标记，连同前面的地名。**是否算总公司由研究者定口径**（通常：分支机构不是独立法人，记录可以归到总公司，但要标记）。
4. 去组织形式：按后缀词库从长到短剥（集团股份有限公司、有限责任公司、有限合伙…）。
5. 剥开头的地区：省级名称、常见城市（可带省/市/区/县等后缀），可连续（广东省深圳市）；词库没有的城市，用 jieba 第一个词的地名标记且带行政区划后缀才算。**不要单凭 jieba 的 ns 标记**——"云遥"这类字号常被误标为地名。
6. 剥末尾的行业词：在整串名称上从后往前按行业词库最长匹配，可连续（信息/科技）；剩余至少 2 个字。**不要依赖分词边界**（jieba 可能把"博通科技"切成"博/通科技"）。
7. 剩下的是字号。剩下的只有行业词时（上海汽车 → R=上海、I=汽车），字号为空，核心名称退回行业词并标记。

**词库要按数据补充**：用 jieba 统计全库词频，从高频词中人工挑出行业词、地区词（与英文流程挑泛用词的做法相同），请研究者核对。

## 3. 简称

中文数据库中简称极多（证券简称、新闻和年报中的惯称、招聘数据中的自填名称）。简称长度通常 2–6 个字，全称 10 个字以上，直接比较全称与简称得分很低，所以要**先由全称猜出可能的简称，再比较**：

| 规则 | 例子 |
|---|---|
| X | 京东方科技集团 → 京东方 |
| R + X | 中国 + 联通 → 中国联通 |
| R 首字 + X | 中国移动 → 中移动 |
| R 首字 + I 首字 | 上海汽车 → 上汽 |
| X 前两/三字 | 海康威视 → 海康 |
| X + I 前两字 | 景栗信息科技 → 景栗信息 |

`abbreviations()` 生成以上候选，规则可以随时增加（统计已知"全称-简称"对的结构，如 RXIO → R[1]X）。`is_subsequence()` 判断简称的字是否按顺序出现在全称中（"跳字"简称），用来召回规则没覆盖的简称。

## 4. 打分

- 相似度（资料中的公式）：(len(a)+len(b) − 编辑距离) / (len(a)+len(b))，插入、删除代价 1，替换代价 2，即 Indel 相似度（`similarity`）。
- **分部加权**（`weighted_score`）：字号、行业、地区分别算相似度，按 8:1:1 加权；只比较两边都有的部分（一边缺地区不扣分）。解决资料中"麟云科技"与"云遥科技"因共享"科技"得高分的问题：未加权 0.75，加权后 0.56。
- 简称与全称（`best_abbr_score`）：全称所有可能简称中，与该简称相似度最高者。
- 资料中以 ≥50% 或更高分数为候选、再人工审核；本 skill 中分数只用于**生成和排序候选**，是否接受仍走规则分流、AI 判断、审核的流程。

## 5. 中文特有的风险与做法

- **同字号不同地区**（"华夏"、"中天"、"金石"等字号在各地都有）：字号相同不能直接接受，证据卡必须有注册地、成立日期、经营范围、法定代表人；有统一社会信用代码就直接用代码。
- **两字字号和两字简称**：同名风险极高，一律交给 AI/人工，不自动接受。
- **集团与子公司**：同字号的集团、子公司、分公司很多（"XX 集团"、"XX 科技"、"XX 投资"），按归属口径判断（与英文流程的母公司/子公司口径相同）。
- **改名**：工商变更、上市后改名、证券简称变更（含 ST、*ST 前缀和"退市"后缀）——把曾用名和历史证券简称都收进名称列表（企查查、天眼查、Wind、CSMAR 的公司名称变更表）。
- **中英文混合**：外资企业的中文名与英文名（如"阿里巴巴"与 Alibaba）要分别标准化，作为同一公司的不同名称；跨语言匹配时可借助股票代码、官网域名。
- **简称包含行业字**："中银"既可能是中国银行，也可能是其他"中 X 银行"；简称越短越要靠证据卡判断。

## 6. 证据卡字段（中文数据）

两侧名称、字号、地区、成立日期、注册地、经营范围（截短）、法定代表人、注册资本、统一社会信用代码、股票代码与证券简称、曾用名、所属集团或母公司。AI 判断说明把英文模板中的"议题代码、catcode"换成"经营范围、行业分类（国民经济行业分类或证监会行业）"。
