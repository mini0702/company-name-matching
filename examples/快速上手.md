# 快速上手（约 5 分钟）

用 9 个名称的小例子把全部脚本跑一遍。例子里有四种典型情况：
- 曾用名（Ion America 是 Bloom Energy 的旧名）；
- 法定名 + d/b/a（Maplebear Inc. D/B/A Instacart）；
- 名字相似但不是一家（InsightSquared ↔ LightSquared）；
- 收购方名义（eBay Inc. (StubHub)）和名字被拆成两个词（Supply Scape）。

## 0. 准备

```
pip install pandas scikit-learn openpyxl
```

在一个空文件夹里运行下面的命令。`$K` 代表本 skill 所在目录，Windows 下写成完整路径即可。

## 1. 名称标准化 → 名称变体表

样本一侧每个名称一行（`sid,name`），同一家公司的所有名字都列上。目标一侧每个名称写法一行（`tid,name` + 证据列）。

```
python $K/scripts/name_std.py $K/examples/sample_names.csv s.csv --id sid
python $K/scripts/name_std.py $K/examples/target_names.csv t.csv --id tid --obo
```

`--obo` 只用于申报类数据：拆出"on behalf of"后被代表的客户，提交方（游说公司）不参与匹配。

## 2. 候选 → 预筛 → 证据卡

```
python $K/scripts/candidates.py s.csv t.csv cand.csv
python $K/scripts/prefilter.py cand.csv pre.csv
python $K/examples/make_cards.py pre.csv $K/examples/target_names.csv cards.csv
```

预期结果：
- InsightSquared ↔ LightSquared 被预筛排除，因为首词不同。
- Supply Scape 因为“只差空格”被保留。
- Bloom Group 因为核心名称相同被保留，交给后面判断。

## 3. AI 判断（在 Claude Code 里，由主会话调用子代理）

```
python $K/scripts/ai_batches.py prepare sonnet --cards cards.csv --dir B --labels $K/examples/labels.json
python $K/scripts/ai_batches.py prompt sonnet --dir B --guide AI判断说明.md
```

`AI判断说明.md` 由 `templates/AI判断说明.md` 改写而来，要写明本任务的口径。

1. 用 `prompt` 打印出的提示词，对每个批次各开一个 `model: sonnet` 的子代理，子代理写出 `B/sonnet_NNN.json`。
2. 运行 `check sonnet --dir B`，检查结果是否齐全。有缺的卡，再运行一次 `prepare sonnet` 就会补出缺的批次。
3. 运行 `prepare opus`，用 `model: opus` 的子代理复核，然后运行 `check opus`。
4. 运行 `merge --cards cards.csv --dir B --out dec.csv --manual manual.csv`。
5. 运行 `prepare web --cards cards.csv --dir B --decisions dec.csv`，上网核实，然后再运行一次 `merge`。
6. 研究者在 `dec.xlsx` 的“人工判断”表第 2 列填 是 / 否 / 不确定，保存并关闭，再运行一次 `merge`。填的结果会存进 `manual.csv`，不会丢。

审核已有匹配时，加 `--mode audit`。这时 Sonnet 判否或不确定的才交给 Opus，两个都判否才算错配。

## 4. 审核与错误率

1. 准备两张表：
   - **总体表**：每个待审对象一行，列为 pid、layer，以及给审核员看的证据。
   - **设计表**：列为 layer、n（抽样数，留空表示全审）、bad（这一层判哪个答案算错）、question（这一层要回答的问题）。
2. 抽样：

```
python $K/scripts/audit.py make --pop pop.csv --design design.csv --dir AUD
```

   这一步只能运行一次，否则会换掉已经审过的样本。

3. 初审员在 `AUD/审核表.xlsx` 填“审核”列。
4. 生成裁定表：

```
python $K/scripts/audit.py ruling --dir AUD [--suggest 复核.json]
```

   研究者在 `AUD/研究者裁定.xlsx` 填“你的裁定”列。

5. 计算错误率：

```
python $K/scripts/audit.py score --dir AUD
```

   结果写进 `AUD/审核结果.xlsx`，同时给出两种口径（只计确认的错误、把不确定也算错）和 3/n 上界。

## 5. 然后

- 把审核发现的系统性问题改成规则，全样本重跑，再审一次。
- 出对照表和变量，与官方汇总、旧变量核对，再另写一个程序独立重算一遍。
- 方法文档按 `reference/流程详解.md` 末尾的模板写。
