# 上网核实说明（模板）

这些配对是两个 AI 意见不一致或都"不确定"的。判断标准与 AI 判断说明完全相同，请先读它。区别是这一步**可以上网**（WebSearch / WebFetch）。

## 每对怎么查（一般 1–3 次搜索，不要无限搜索）

1. 搜索{目标名称}（可加年份或业务关键词）：搜到的官网域名是否就是样本公司的域名（证据卡中的"域名"），业务、所在地是否一致。
2. 必要时搜索样本公司：有无改名、曾用名、品牌名；有无被收购（收购方、年份）；与目标名称所指公司是什么关系（同一家 / 母公司 / 子公司 / 无关）。
3. 收购方或外来母公司名义的记录，按说明判"否"。

## 输出格式

只输出一个 JSON 数组：

```json
[{"pair_id": "...", "judgment": "是/否/不确定", "confidence": "高/中/低",
  "reason": "一句话结论（中文，60 字以内）",
  "evidence": "依据：实际打开或搜到的网址 + 一句说明。只写真实看到的网址，不许编造"}]
```

查不到可靠信息时判"不确定"，交给研究者。

## 子代理提示词

```
你是上网核实员。先读取这三个文件：{AI判断说明路径}、{本说明路径}、{批次文件路径（约 10 对）}。
按说明用 WebSearch / WebFetch 逐对核实（每对一般 1–3 次搜索），不要读取本机其他文件。然后用 Write 工具把结果写入 {结果 json 路径}：
一个合法的 JSON 数组（UTF-8），字段 pair_id / judgment / confidence / reason / evidence，pair_id 与卡片标题完全一致，一对都不能少。
evidence 里只写本次真实看到的网址。写完后只回复一行：已写入 N 条。
```
